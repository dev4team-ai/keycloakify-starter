# keycloakify-starter — ВЫВЕДЕН ИЗ ОБРАЩЕНИЯ (2026-08-27)

> ⛔️ **Репозиторий больше не используется. Ничего сюда не коммитьте.**
>
> Тема входа Keycloak целиком живёт в **[`keycloak-ui`](https://github.com/dev4team-ai/keycloak-ui)**:
> там и исходник (React/Keycloakify), и `Dockerfile`, который собирает образ темы.

## Что здесь было

Собранный артефакт темы (`login/*.ftl`, JS-бандлы, `messages_*.properties`, письма) + `Dockerfile`,
который упаковывал эти файлы в образ `protonmath/keycloakify-starter`. Файлы переносились сюда
из `keycloak-ui` вручную.

## Почему выведен

Ручной перенос — единственное, что связывало исходник и артефакт, и связь рвалась: правки делали
прямо здесь (кастомные HTML-письма, русские тексты login-темы), в исходник они не попадали, и любая
честная пересборка их затирала. К августу 2026 репозитории разошлись настолько, что пересборка из
`keycloak-ui` откатила бы часть работы, сделанной за полгода.

Что сделано вместо этого:

- кастомные письма закреплены в исходнике (`keycloak-ui/src/email/**`, `npx keycloakify own`);
- русские тексты login-темы перенесены в `keycloak-ui/src/login/i18n.ts` (`withCustomTranslations`);
- образ темы собирается multi-stage `Dockerfile`-ом в `keycloak-ui` — ручного переноса больше нет.

Имя образа не менялось (`protonmath/keycloakify-starter`), поэтому `gptbot-helm` и
`clusters/common/image-versions.yaml` править не потребовалось.

## Если нужно посмотреть историю

Последнее состояние артефакта — коммит перед этим. Оно побайтово совпадает с тем, что собирает
`keycloak-ui` (проверено сравнением 251 файла), так что ничего уникального здесь не осталось.

**Репозиторий можно архивировать на GitHub.** TeamCity на него больше не смотрит: build config
`keycloak-theme` (бывший `keycloakify-starter-theme`, id сохранён) собирает `keycloak-ui`.
